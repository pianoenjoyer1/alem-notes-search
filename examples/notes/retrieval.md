# Поиск и RAG

Retrieval — этап поиска подходящих фрагментов в базе знаний. Поиск возвращает текст и ссылку на источник. В RAG эти фрагменты затем передают языковой модели как контекст для ответа.

TF-IDF увеличивает вес слов, которые встречаются редко во всей коллекции. Косинусная близость сравнивает направление векторов запроса и документа. Длинный текст не получает преимущество только из-за длины.

Chunking разбивает документ на небольшие фрагменты. Слишком короткий фрагмент теряет контекст, слишком длинный содержит лишнюю информацию. Номер строки помогает быстро проверить источник.

Retrieval evaluation can measure whether the expected source appears among the first k results. This lexical baseline matches words; it does not understand synonyms or translate a query.
