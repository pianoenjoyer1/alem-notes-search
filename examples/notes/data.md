# Данные для ML

Валидация оценивает модель на данных, которые не использовались для подбора её параметров в обучении. Тестовую выборку сохраняют для финальной оценки. Дубликаты между выборками могут привести к утечке данных.

Пропуски не всегда являются ошибкой. Перед заполнением пропусков важно выяснить их причину. Среднее, медиана и отдельная категория подходят для разных ситуаций.

Деректер сапасы модель нәтижесіне әсер етеді. Бос мәндер мен қайталанатын жолдарды тексеру керек. Оқыту және тест жиынтықтары бір-бірінен бөлек болуы тиіс.
