# Python и тесты

Словарь Python хранит пары ключ-значение. Counter подсчитывает частоту элементов. pathlib помогает работать с путями без ручного объединения строк.

Автоматические тесты проверяют конкретное поведение программы: пустой ввод, неизвестные слова, неправильный путь и ожидаемый порядок результатов. unittest входит в стандартную библиотеку Python.
