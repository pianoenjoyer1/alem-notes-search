# Alem Notes Search

Локальный поиск по конспектам на русском, казахском и английском. Возвращает фрагменты Markdown/TXT с именем файла, номером строки и оценкой близости к запросу.

**Python 3.9+ · Без внешних зависимостей · CLI и веб-интерфейс**

## Зачем

В папке с учебными заметками трудно вспомнить, где описан нужный термин. Alem Notes строит небольшой TF-IDF индекс и показывает подходящие фрагменты. Это самостоятельный lexical retrieval baseline — компонент, который можно использовать перед генерацией ответа в RAG.

## Быстрый запуск

Из корневой папки проекта:

```bash
python3 search.py examples/notes "retrieval"
python3 search.py examples/notes "деректер" --limit 3 --json
python3 server.py
```

Открой **http://127.0.0.1:8765**. Примеры запросов есть прямо в интерфейсе. На Windows вместо `python3` обычно используется `python`.

Чтобы искать по своим заметкам:

```bash
python3 server.py /path/to/notes --port 8765
```

Нужны UTF-8 файлы `.md` или `.txt`. Индекс обновляется при перезапуске. Содержимое обрабатывается на компьютере; внешние API не вызываются.

## Как устроено

1. `read_passages` обходит папку и делит текст по пустым строкам, ограничивая фрагмент 12 строками.
2. `tokenize` нормализует Unicode и регистр, выделяет слова и числа.
3. `SearchIndex` считает `idf = log((1 + N) / (1 + df)) + 1` и вес `1 + log(tf)`.
4. Векторы нормируются до единичной длины. Скалярное произведение даёт cosine similarity.
5. Нулевые совпадения отбрасываются, остальные сортируются по score. При равенстве используется имя файла и строка.

```text
notes/*.md → passages → TF-IDF index ← query
                             ↓
                    ranked source fragments
                             ↓
                         CLI / web
```

`search.py` содержит алгоритм и CLI, `server.py` — HTTP-обработчики, `web/index.html` — интерфейс без сборщика. В `examples/notes` находятся самостоятельно составленные демонстрационные тексты.

## Проверка

```bash
python3 -m unittest discover -s tests -v
```

Проверяются ранжирование, кириллица и Unicode, пустые запросы и индекс, источники и строки, ограничения ввода, HTTP API и недоступность произвольных файлов через сервер.

## Ограничения

- Поиск лексический: нет нейросети, понимания синонимов, перевода или генерации ответа. Запрос на русском не найдёт казахский синоним без совпадения слов.
- Score — близость векторов, а не вероятность правильного ответа.
- Нет стемминга: разные окончания слов могут не совпадать.
- Индекс находится в памяти; это инструмент для небольших папок, не промышленная поисковая система.
- Сервер предназначен для локального запуска на `127.0.0.1`.

## Идеи развития

- Сравнить TF-IDF с BM25 на размеченном наборе запросов.
- Добавить сохранение индекса и обновление изменённых документов.
- Измерять recall@k по списку ожидаемых источников.
